# WebGunfight 在线试玩

[打开游戏](https://2683445453.github.io/qmqz-play/)

这是 WebGunfight 的 GitHub Pages 部署仓库。`main` 分支根目录存放 Unity Web 构建产物，GitHub Pages 从这里发布试玩站。打开网页即可游玩，无需安装 Unity。

首次进入游戏时填写昵称。需要离线游玩时，联网点击页面上的「下载完整离线资源」，等提示「可离线游玩」后，再用同一浏览器和网址打开。角色与进度保存在当前浏览器中。

Unity 工程、构建命令和项目结构见 [WebGunfight 源码仓库](https://github.com/2683445453/WebGunfight)。
